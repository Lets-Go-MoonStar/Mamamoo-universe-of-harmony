# Assets

This folder holds the visual pack the prototype expects under `res://assets/...`.

## Current state

The original illustrated pack was **never included** in the GitHub upload
(`Add files via upload`, Oct 2026). The PNGs here are **procedural placeholders**
generated by `tools/generate_placeholder_assets.py` so Godot can import and the
game / headless tests can boot.

Placeholders use sized sheets with a light gradient + 32px checker so atlas
cells are visible. They are **not** final art; shipping real illustrations is
blocked until the art pack is provided (same relative paths).

## Restore the real pack

1. Drop the real PNG tree on top of this folder (same relative paths).
2. Or re-run the generator only for missing files:
   `python tools/generate_placeholder_assets.py`
   Force-refresh placeholders: `python tools/generate_placeholder_assets.py --force`
3. Re-import in Godot (`--headless --import` or open the project once).

Do not commit large binary art unless the team agrees on Git LFS or an external
asset bundle.

## Audio (`assets/sfx/`)

`Sfx.play(kind)` loads `res://assets/sfx/{kind}.wav` (or `.ogg`) **first**, then
falls back to procedural tones. Generate starter WAVs:

```sh
python tools/generate_sfx_placeholders.py
```

Replace those files with real recordings keeping the same filenames (`solar.wav`,
`phase.wav`, `clear.wav`, …). See `assets/sfx/README.md`.
